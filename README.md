# 🌍 Noise Pollution Awareness

An interactive educational website designed to raise awareness about **noise pollution** and its impact on people, animals, and the environment.

The project aims to make learning about noise pollution fun, engaging, and accessible, especially for children. Through interactive visualizations, educational content, and a simple mini-game, users can explore different sources of noise, understand their effects, and discover ways to reduce noise pollution in everyday life.

Our goal is to encourage a quieter, healthier, and more environmentally friendly world. 🌱
